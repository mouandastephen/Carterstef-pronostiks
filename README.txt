CARTERSTEF-PRONOSTIKS
Site statique simple, prêt pour Netlify.

Fichiers:
- index.html
- style.css
- script.js
- assets/logo-carterstef-pronostiks.png

Déploiement:
1. Décompresser le ZIP.
2. Ouvrir Netlify et utiliser Deploy/Drag and Drop.
3. Déposer le dossier Carterstef-pronostiks.
4. Le site sera publié sur une adresse netlify.app.

Pour ajouter les vrais pronostics, modifier le tableau 'data' dans script.js.
Ne pas publier de probabilités inventées : utiliser des estimations fondées sur les données disponibles.
